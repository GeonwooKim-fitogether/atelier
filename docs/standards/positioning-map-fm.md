**포지셔닝 맵 FM (책 2장 p56 정합)**:

**필수 형태**:
- **밝은 회색 배경 단일 평면** (사분면 블록 분리 X)
- **X축·Y축 선** = 평면 안 가로/세로 line (격자 분리 X)
- **dot = 실제 좌표 위치** (position absolute · X·Y 값 = 정합 매핑)
- **축 라벨 = 평면 안 모서리** (외부 부유 X)
- **축 의미 설명 박스** = 무엇이 단일/멀티·무료/유료인지 정의

**금지**:
- 4 사분면 grid 블록으로 나누어 dot 일렬 나열 = 포지셔닝 본질 잃음
- 축이 평면 밖에 부유
- 축 의미 설명 없음
- 그룹핑 1개 layer만 (시장 강도만·권역만 등)

**다층 그룹핑 한 번에 박는 5 layer**:
1. **위치** = X·Y 좌표 (1차 의미)
2. **dot 크기** = 시장 강도 (다운로드·매출)
3. **dot 색** = 권역 분리 (KR·US·MULTI 등)
4. **dot 강조 (★·glow)** = 우리 자리·핵심
5. **음영 영역** = 빈자리(gap) 시각화 + 점선 테두리·shape = 보조 의미 (신생·성숙 등)

**범례 필수**: 한 자리에 dot 색·크기·shape·음영 의미 정리

**Why:** CEO 본질 정정 (2026-05-31) *"왜 포지셔닝의 본질을 잃어버린거야?! 왜 이걸 4사분면으로 나눠서 일자로 나열하는거야? 이렇게 포지셔닝을 누가 하니?"* 포지셔닝 = 연속 좌표 의미. 블록으로 나누면 카테고리 분류·포지셔닝 X.

**How to apply:** 모든 포지셔닝 맵 박을 때 default. 4 사분면 grid 박으면 즉시 멈춤. 좌표 평면으로 다시 박음. 그룹핑 layer 최대한 (5+) 한 맵에 박음.
