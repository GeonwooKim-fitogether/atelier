# 기획 현황판 — 껍데기와 데이터를 갈라 둔 곳

> 한 줄 요지: **정본 현황판(`workflows/type1-external-service.html`)은 이제 손으로 고치지 않는다.** 카드 한 장에 해당하는 작은 파일을 고치고 조립기를 돌리면 정본이 다시 만들어진다.

## 왜 갈랐나

정본 현황판은 원래 **300KB짜리 한 덩어리 HTML**이었다. 갱신하려면 그 덩어리를 열어야 했고, 그래서 아무도 갱신하지 않았다. 2026-08-30에 그 결과가 드러났다 — 한 세션이 조사·PRD·시제품·브리프를 만들어 전부 푸시했는데 현황판에는 한 줄도 반영되지 않았고, 산출물 열다섯 중 넷만 화면에 있었다.

그때 세션이 내린 처방이 틀렸던 것도 함께 적어 둔다. **갱신하기 어려우니 갱신하기 쉬운 새 판을 만들자**로 흘러 두 번째 현황판을 만들었는데, 그것은 이미 2026-08-27 결정 1이 폐기한 체계였다. 헌장 §3.6이 그 교훈을 이렇게 못 박았다 — *"새로 만들지 말고 정본을 갱신하기 쉽게 고친다."* 이 폴더가 그 조치다.

## 무엇이 어디에 있나

| 파일 | 무엇인가 | 세션이 고치나 |
|---|---|---|
| `shell.html` | 껍데기. 머리말·CSS·왼쪽 사이드바·필터 스크립트. 카드가 들어갈 자리는 `{{CARDS}}` 한 곳이다 | 거의 안 고친다 |
| `cards/*.html` | 카드 한 장의 전체 마크업. 단계마다 파일 하나 | **여기를 고친다** |
| `board.json` | 카드의 순서와 목차(이름·상태). 카드 사이의 공백과 주석도 여기 담긴다 | 카드를 새로 넣거나 뺄 때 |
| `build.mjs` | 위 셋을 합쳐 정본 HTML을 만든다. 의존성 없음 | 안 고친다 |

카드 파일 크기는 4KB에서 137KB 사이이고, 대부분 10~30KB다. **300KB 덩어리를 열 일이 없어진다.**

## 어떻게 쓰나

```bash
# 카드를 고친 뒤 정본을 다시 만든다
node workflows/board/build.mjs

# 고치지 않고, 정본이 조각들과 일치하는지만 본다 (다르면 종료코드 1)
node workflows/board/build.mjs --check
```

### 이번 회차 내용을 카드에 넣는 순서

1. 어느 단계의 이야기인지 정하고 `cards/stage-0N.html`을 연다.
2. 카드 본문 **맨 위**에 블록을 하나 더한다. 가장 최근 소식이 위에 오는 것이 이 게시판의 규약이다.
3. 상태 문구(`stage-card-status`)가 달라졌으면 카드 안에서 고치고, **`board.json`의 같은 항목도 함께 고친다.**
4. `node workflows/board/build.mjs`를 돌린다.
5. 정본 HTML의 변경을 산출물과 **같은 PR에** 담는다 (헌장 §3.5).

### 블록 서식

카드 본문의 블록은 인라인 스타일로 쓴다. 자주 쓰는 셋은 이렇다.

| 쓰임 | 배경 / 테두리 | 제목 색 |
|---|---|---|
| 완료된 일 | `rgba(110,231,183,0.09)` / `rgba(110,231,183,0.35)` | `#6ee7b7` |
| 이번에 새로 들어온 일 | `rgba(147,197,253,0.09)` / `rgba(147,197,253,0.35)` | `#93c5fd` |
| 주의·정정 | `rgba(253,230,138,0.06)` / 왼쪽 테두리 `#fde68a` | `#fde68a` |

## 장부가 거짓말하지 못하게 돼 있다

`board.json`의 이름과 상태는 **카드 파일 안의 실제 값과 대조된다.** 목차만 고치고 카드를 안 고치면 조립이 멈추고 어느 항목이 어긋났는지 알려 준다.

```
[board] 목차와 카드가 어긋난다:
  - control: board.json의 status가 카드와 다르다
    목차: 열림 0 · 전부 판정됨
    카드: 열림 6 · 닫힘 8
```

이 대조가 있어서 목차는 요약일 뿐 별도의 진실이 되지 못한다. 두 곳에 같은 사실을 적으면 반드시 어긋나는데, 어긋나는 순간 멈춘다.

## 분리가 무손실임을 어떻게 확인했나

카드를 떼어낸 직후 조립기를 돌려 **원래 파일과 바이트 단위로 같은지 대조**했고, 완전히 동일했다(306,872자). 즉 이 분리는 내용을 한 글자도 바꾸지 않았다. 앞으로도 `--check`가 같은 대조를 언제든 다시 한다.
