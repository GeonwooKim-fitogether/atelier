# Intake — mobile-rosary

## Pain raw (CEO 발화)

내가 성당을 다니고 묵주기도를 하는데 주로 집에 대중교통을 타고 오는 길에 하거든. 그런데 이게 묵주랑 기도문을 가지고 다니지 않으면 너무 불편한거지. 그래서 스마트폰으로 쉽게 할 수 있으면 좋겠어.

**보강 정보** (1.3 대화에서 추출):
- 도구 셋 다 마찰 — 묵주(50번 넘는 성모송 횟수 추적), 기도문책(외우지 못한 사이사이 기도문), 날짜(연속성, 하루 빠지면 재시작).
- 일부 기도문은 외움(성모송, 주의기도). 사이사이 끼어있는 기도문은 안 외움.
- 막히는 구체 순간: 성모송 세다가 끊김 / 기도문 잊어버림 / 일자 잊어버림 — 셋 다.
- 피로하면 반복 구조로 졸음.
- 대부분의 신자가 묵주기도를 단편 세션(저녁·이동)에 함 = 피로 시간대.

## 배경 지식 (도메인 1차 조사)

- 묵주기도 = 묵주알 굴리며 예수 그리스도의 신비(환희·빛·고통·영광)를 성모 마리아와 함께 묵상.
- 진행: 십자가 → 성호경 + 사도신경 → 주님의 기도 → 성모송 3 → 영광송 + 구원의 기도 → 신비 5단 (각 단: 신비 묵상 + 주님의 기도 + 성모송 10 + 영광송) → 마무리.
- 도구 역할: 묵주 = 횟수·위치 추적 / 기도문책 = 정확한 기도문 텍스트.

Sources: 나무위키, 가톨릭 기도서, 가톨릭타임즈, Arlington Diocese 가이드 등.

## Pain Point 재정의

묵주기도를 하는 사람이 *단편 세션(저녁·이동)*에 기도하려 할 때, 두 차원의 마찰이 진행을 막는다:
- **(a)** 묵주·기도문책 도구 부재 → 3중 추적(횟수·텍스트·일자) 어려움
- **(b)** 피로 시간대 + 반복 구조 → 졸음으로 진행 좌초

## 5 Whys

- **Why 1**: 도구가 손에 없으면 50번 넘는 성모송 횟수 / 외우지 못한 기도문 텍스트 / 연속 일자 — *세 추적 부담*을 기억만으로는 다룰 수 없어 진행 막힘.
- **Why 2**: 마찰이 세 차원(횟수·텍스트·일자) 모두에서 발생 + 졸음 차원까지. 단일 임시 마찰이 아닌 *시스템적 광범위 마찰*. 진짜 Pain 신호 4개(반복·우회·비용·일반화) 모두 잡힘.

## 근본 원인

묵주기도는 *외부 도구 의존도가 높은 3중 추적 구조* + *반복 구조에 따른 졸음 유도성*을 갖는다. 그런데 대부분의 신자가 이 기도를 *최고 컨디션이 아닌 단편 세션(이동·저녁)*에 한다. 결과: *도구가 손에 없는 환경* + *졸리는 시간대* 두 가지가 *동시에 자주 겹침* → 진행 좌초가 일상적.

## 5축 (backend organizer — Stage 02·03 입력 layer)

- **context**: 당사자(CEO, 성당 신자). 대중교통 이동 중(집 가는 길) + 저녁 늦게 + 단편 세션. 대부분의 신자가 비슷한 시간대·환경 패턴.
- **behavior**: 묵주 + 기도문책 휴대. 일부 기도문 외움(성모송·주의기도). 사이 기도문 안 외움. 도구 부재 시 진행 좌초. 일자 빠지면 재시작.
- **needs**: 표면 — 도구 없이 묵주기도 진행. 그 너머 — 횟수·텍스트·일자 추적 + 졸음 관리까지 *집중 지키며* 기도하기.
- **attitude**: 매번 막힘 인식. 연속성에 가치(재시작 부담 큼). 졸음 좌초도 일상으로 인식.
- **motivation**: 영성 습관 유지. 최고 컨디션 아닌 단편 세션에도 기도 우선순위 → 시간 부족과의 절충.
