### 검증된 Pain (한 문장)

> ***매일 묵주기도를 영성 의례로 삼는 비-헤비 가톨릭 신자가, 단편 세션(이동·저녁) 도구 없는 환경에서 좌초되지 않기 위해 손가락·관절·종이 노트·분산·반지·smart device 등 *다층 우회 비용*을 지불하고 있는 상태. 시장은 물리·디지털·smart hardware 3 layer로 응답하지만 어느 것도 *단편 세션 × 졸음 × 가볍게* 조합을 풀지 못한 상태.***

*본질 핵심*:
- **우회 비용 지불** = 진짜 Pain. 3중 추적·졸음은 *증상*.
- **시장 3 layer 응답**(물리/디지털/smart)이 Pain 진짜성 *매우 강* 검증. 단 *Vatican smart device의 "mixed blessing"* = 기존 시도 *부분 성공·만족 X* → **gap 자리 존재**.
- 시장·사용자 raw 모두 *우회·도구 다양*을 가리킴 — 비용 지불할 만큼 *Pain의 지속성·강도·시장 인지* 모두 확실.

### Output → 3.2 Persona input
- **Owner 부분 narrow**: 비-헤비 가톨릭 신자 + 단편 세션 기도 + 도구 미휴대 + 매일 의례 의지 + *우회 학습 의지* + *기존 디지털 시도 만족 X 경험*
- **본질 frustration**: 다층 우회 비용 지불 (학습·시간·정서·금전 — eRosary $109까지) → Persona Frustrations 핵심
- **본질 behavior**: 손가락·관절·노트·분산·반지·앱 동시 사용 (어느 도구도 완전 X) → Persona Behaviors 핵심

### Output → 3.3 포지셔닝·경쟁사 input
- **경쟁 풍경 3 layer**: 물리 도구 / 디지털 앱 / smart hardware. 각 layer 차별점·gap 후속 분석.
- **포괄적 경쟁자**: 사용자 자체 우회 행동 (손가락·관절·노트·분산) — *경쟁 제품 없이도* 사용자가 자가 해결 중.
- **gap 가설 후보**: *단편 세션 + 가벼움 + 도구 없는 환경 + 졸음·집중 대응* — 어느 layer도 못 채움.

## 3.6 사람들이 지금 어떻게 시도하고 있나? [본질 질문 ③-d]

사람들이 이 문제를 **지금 어떻게든 스스로 해결하려 시도하는 방식**을 4가지로 본다. 이 분류가 **우리 제품을 어떻게 만들지** 알려준다.

### 왜 이 분석이 필요한가

- 사람들이 **이미 자기만의 방법으로 시도 중**이면 → 그 방식을 디지털로 자연스럽게 도와주면 된다 (가볍게 만들 수 있음)
- 사람들이 **시도조차 안 한다면** → 완전히 새로운 사용법을 가르쳐야 한다 (어려운 길)
- 아무도 시도 안 한다면 → **시장이 없다는 신호 (포기)**

### 4가지 시도 방식과 우리 제품 방향

| 시도 방식 | 어떤 사람들인가 | 묵주기도에서 실제 모습 | 얼마나 많은가 | 우리가 갈 길 |
|---|---|---|---|---|
| **① 기존 방식 그대로** | 지금 하던 방법은 유지하고 도구만 바꿔봄 | 묵주 없을 때 **손가락으로 세거나** 한 번에 다 못 하면 **짧게 나눠서** 함 | **많음 ✓** | 기존 묵주기도 흐름은 그대로 두고 **디지털로 가볍게 도와줌** |
| **② 다른 분야에서 빌려옴** | 비슷한 다른 분야의 도구·습관을 가져와 응용 | **명상 앱**처럼 가이드 듣거나 **잠 들 때 듣는 podcast**로 대신함 | **어느 정도 ✓** | 명상·sleep 앱의 **가벼운 흐름**을 가져와 적용 |
| **③ 자기만의 방식 발명** | 어디서도 본 적 없는 자기만의 방법을 만듦 | **「묵주기도 노트」** 같은 종이 도구를 직접 만들어 씀 | 적음 | 완전 새 사용법 강제는 **채택 부담 큼**, 부분만 적용 |
| **④ 시도조차 안 함** | 아예 포기하거나 신경 안 씀 | 해당 없음 — 사람들이 다 어떻게든 시도하고 있음 | 없음 ✗ | **시장 없음 신호 (포기)** |

### 결론 — 우리 제품 방향 결정

사람들이 **① 기존 방식 그대로 + ② 다른 분야에서 빌려와서** 이미 활발하게 시도 중. **④ 시도 안 함**은 없음 → **시장 있음 확인**.

→ 우리 제품은: **기존 묵주기도 흐름은 그대로 두고 디지털로 가볍게 도와주면서, 명상 앱처럼 가벼운 흐름을 빌려와 졸음·짧은 시간 대응을 추가**. 완전 새 방식 강제하지 않음.
