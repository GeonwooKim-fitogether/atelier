# 화면 지도와 시나리오 검증 (06-e) — mobile-rosary V1

> 이 문서가 답하는 질문 둘: **① 화면이 왜 이만큼이고 각각 왜 필요한가** · **② 사용자가 실제로 겪을 길을 하나씩 걸어 보면 어디에서 막히나.**
> 입력: [`06-prd.md`](./06-prd.md) §4·§5·§8 · [`06-service-design.md`](./06-service-design.md) §1·§2 · [`06-screen-spec.md`](./06-screen-spec.md).
> 이 문서는 새 결정을 내리지 않는다. 앞 세 문서에 **적혀 있는 것들을 한 장에 놓고 서로 맞는지 대조**한다. 대조가 잡아낸 결함은 §4에 있고, 그 결함을 어느 문서의 어디에서 고쳤는지도 §4에 적었다.

---

## 1. 화면 지도 — 있는 것 전부와 각각이 있는 이유

화면 3 · 시트 4 · 화면 안의 상태 9. 아래 표에 없는 화면은 V1에 없다.

| # | 화면 / 시트 / 상태 | 왜 있어야 하나 (이것이 없으면 무엇이 안 되나) | 담는 요구사항 |
|---|---|---|---|
| **A** | **홈** | 유일한 진입점. "지금 시작할 수 있나, 이어서 바치면 되나"를 3초 안에 답한다 | FR-01·02·03·04·06·07·18·29·30 |
| A-1 | 홈 · 첫 실행 / 진행 없음 | 지향 하나("오늘의 지향"), 이어가기 카드 없음, 시작 단추 "시작". **비어 보이는 것이 정상**이다 — 이 상태가 기본이고 카드가 생기는 것이 예외 | FR-30 |
| A-2 | 홈 · 진행 있음 | 이어가기 카드가 시작 단추 **위에** 나타나고, 단추는 "처음부터 다시"로 바뀐다. 카드에 자리·시각·**신비**를 적는다 | FR-02·03 |
| A-3 | 홈 · 한국어 음성 없음 | 안내 한 줄(촛불색). 없으면 사용자는 앱이 고장났다고 여긴다 | §8 오류표 |
| **B** | **기도** | 77단계를 진행한다. "지금 내 차례인가, 어디쯤인가"를 화면을 보지 않고도 알린다 | FR-10~17·18·20~24·26·28·31 |
| B-1 | 기도 · 읽는 중 | 앱이 앞 절을 읽는다. 알 테두리가 차오른다 | FR-11·15 |
| B-2 | 기도 · 내 차례 | 받는 사이. 뒷 절이 촛불색, 알이 4초 호흡 | FR-12·13·15 |
| B-3 | 기도 · 침묵 | 소리 없이 진동만. 알의 상태 표시는 같다 | FR-06·14·15 |
| B-4 | 기도 · 단 전환 | 신비 선포 2200ms, 진동 세 번, 알 확장 맥동 | FR-14·15 |
| B-5 | 기도 · **멈춤** | 전화·홈 버튼으로 앱을 벗어났다가 돌아왔을 때. 자동 저장된 자리에 멈춰 있고 "이어서 바치기 / 홈으로" 둘을 보인다. **없으면 복귀한 사용자가 어디로 가야 할지 모른다** (§4 결함 5) | FR-17·18 |
| **C** | **완주** | 마침을 조용히 확인하고 저장 자리를 지운다 | FR-19·27 |
| **S1** | 시트 · 지향 추가 | 이름 하나(24자). 홈에 머문다 | FR-05 |
| **S2** | 시트 · 받는 사이 | 느리게·보통·빠르게. 홈에 머문다 | FR-07 |
| **S3** | 시트 · **처음부터 확인** | 진행이 있을 때 "처음부터 다시"를 누르면 한 번 묻는다. **없으면 실수 한 번에 자리가 사라진다** (§4 결함 3) | FR-18 |
| **S4** | 시트 · 소개 (i) | 이 시제품이 무엇을 검증하는지. 08 검증 참가자용. 홈 우상단 (i) 에서 연다 (§4 결함 1) | — |

**없는 것과 그 이유** — 탭 바(멘탈 모델이 "열면 바로 시작한다" 하나라서), 설정 화면(설정이 셋뿐이라 홈에 둔다), 통계·달력·공유(톤 규칙 위반), 지향 편집 화면(삭제는 길게 누르기로 충분하다 — §4 결함 4).

## 2. 연결 — 어디서 어디로 가나

```
                    ┌──────────────────────────────────────────────┐
                    │                    홈 (A)                     │
                    │  [오늘의 신비]  [음성 없음 안내 A-3]            │
                    │  [이어가기 카드 A-2 — 진행 있을 때만]           │
                    │  [지향 카드들] [+ 지향 추가]                    │
                    │  [시작 / 처음부터 다시]  [침묵 ○] [받는 사이 ▸] │
                    │  (i)                                          │
                    └──┬──────┬──────┬────────┬──────────┬─────────┘
       이어가기 카드 탭 │      │ 시작 │        │ + 탭      │ 받는 사이 탭   (i) 탭
                      │      │      │        ▼           ▼            ▼
                      │      │      │     S1 지향 추가   S2 받는 사이   S4 소개
                      │      │      │        └───── 닫히면 홈에 머문다 ─────┘
                      │      │      │ "처음부터 다시"(진행 있음)
                      │      │      ▼
                      │      │   S3 처음부터 확인 ── 아니오 → 홈
                      │      │      │ 예 (자리 삭제)
                      ▼      ▼      ▼
                    ┌──────────────────────────────────────────────┐
                    │                   기도 (B)                    │
                    │   B-4 단 전환 → B-1 읽는 중 → B-2 내 차례 → …  │
                    │   (침묵이면 B-3 이 B-1·B-2 를 대신한다)         │
                    │   앱 이탈 ──→ B-5 멈춤 ──[이어서]──→ B-1        │
                    │                        └─[홈으로]──→ 홈 (자리 남음)│
                    │   [잠시 멈춤 → 홈, 자리 남음] [여기서 끝내기 → 홈, 자리 삭제]│
                    └──────────────────────┬───────────────────────┘
                                           │ 77단계 완료
                                           ▼
                    ┌──────────────────────────────────────────────┐
                    │                  완주 (C)                     │
                    │   다 바쳤습니다 · 지향 · 통계 셋 · [돌아가기]     │
                    └──────────────────────┬───────────────────────┘
                                           └──→ 홈 (자리 삭제됨, A-1 로)
```

**뒤로 가기의 뜻** — 홈에서는 앱 종료. 기도에서는 "잠시 멈춤"과 같다(자리 남김). 시트에서는 시트 닫기. 완주에서는 돌아가기와 같다.

**이 그림이 정하는 불변식 하나** — **기도 화면에 들어가는 길은 홈에서 출발하는 셋뿐이고**(이어가기 · 시작 · 확인 뒤 시작), 기도 화면에서 나가는 길은 넷뿐이다(잠시 멈춤 · 끝내기 · 완주 · 앱 이탈→멈춤). 이 밖의 경로를 만들자는 제안은 이 문서를 먼저 고쳐야 한다.

## 3. 시나리오 검증 — 길을 하나씩 걸어 본다

각 시나리오를 화면 지도 위에서 한 걸음씩 밟는다. 걸음마다 "그 화면·요소가 명세에 있나"를 ✓/✗ 로 적는다. ✗ 는 §4의 결함 번호를 단다.

### S-1 · 첫 실행에서 첫 완주까지 (해피 패스)

| 걸음 | 사용자가 하는 일 | 화면 | 명세에 있나 |
|---|---|---|---|
| 1 | 앱을 연다 | A-1 홈(진행 없음). 오늘의 신비가 요일로 정해져 있다 | ✓ FR-01·30 |
| 2 | 지향을 고르지 않고 "시작"을 누른다 | → B-4 단 전환(신비 선포) → B-1 | ✓ FR-29 (조작 한 번) |
| 3 | 앞 절을 듣고 뒷 절을 받는다 × 77 | B-1 ↔ B-2 반복, 단마다 B-4 | ✓ FR-10~13 |
| 4 | 다섯 단을 마친다 | → C 완주. 긴 진동 한 번 | ✓ FR-19·27 |
| 5 | 돌아가기 | → A-1. 이어가기 카드 없음, 단추 "시작" | ✓ |

### S-2 · 도중에 멈추고 이튿날 이어간다

| 걸음 | 사용자가 하는 일 | 화면 | 명세에 있나 |
|---|---|---|---|
| 1 | 화요일 밤(고통의 신비), 제3단 4번째 알에서 "잠시 멈춤" | B → A-2. 카드 "제3단 4번째 알부터 · 방금" | ✓ FR-17·18·03 |
| 2 | 수요일 낮에 다시 연다 | A-2. 홈 머리는 **영광의 신비**(수요일), 카드는 어제 자리 | **✗ 결함 2** — 카드를 누르면 고통을 이어가나 영광으로 바꾸나, 명세에 없었다 |
| 3 | 이어가기 카드를 누른다 | → B-1, 제3단 4번째 알부터 | ✓ (결함 2 처방 뒤: 저장된 신비로 이어간다, 카드에 신비 이름을 적는다) |

### S-3 · 기도 중 전화가 온다

| 걸음 | 사용자가 하는 일 | 화면 | 명세에 있나 |
|---|---|---|---|
| 1 | B-2 에서 전화가 와 앱이 뒤로 간다 | 자리 자동 저장, 정지 | ✓ FR-17, §8 |
| 2 | 통화 뒤 앱으로 돌아온다 | **어느 화면인가?** PRD §8은 "홈의 이어가기 카드로 안내"라 적었으나 iOS 는 떠난 화면으로 복귀한다 | **✗ 결함 5** — 복귀 화면이 없었다. 처방: B-5 멈춤 상태 |
| 3 | "이어서 바치기" | → B-1 그 알부터 | ✓ (처방 뒤) |

### S-4 · 눈을 감고 침묵으로 다섯 단

| 걸음 | 사용자가 하는 일 | 화면 | 명세에 있나 |
|---|---|---|---|
| 1 | 홈에서 침묵 진행을 켠다 | 진동 3연타 예고 | ✓ FR-06 |
| 2 | 시작 | B-3. 알 넘어감 18ms, 단 전환 28-60-28-60-28 | ✓ FR-14 |
| 3 | 받는 사이에 앞 절 몫이 더해지나 | 비화면 채널 명세: 무음이면 앞절 글자수 × 118ms 가산 | ✓ FR-13 |
| 4 | 끝을 어떻게 아나 | 완주 긴 진동 200ms | ✓ FR-27 |

### S-5 · 지향이 둘 — 어머니 병환과 나 자신

| 걸음 | 사용자가 하는 일 | 화면 | 명세에 있나 |
|---|---|---|---|

| 2 | 그 지향으로 2단까지 바치고 잠시 멈춤 | A-2, 카드는 어머니 병환 자리 | ✓ FR-04·17 |

| 5 | 다시 "어머니 병환" 카드를 누른다 | 2단 자리 카드가 돌아와야 한다 | ✓ 명세 / **✗ 시제품 v4 는 자리를 하나만 저장한다** (§4 결함 7, 07 개정 목록) |

## 4. 검증이 잡아낸 것 — 결함 7건과 처방

앞 세 문서를 따로 읽을 때는 보이지 않았고, **길을 걸어 보니** 보였다. 이것이 이 문서가 존재하는 이유다.

| # | 결함 | 왜 문제인가 | 처방 (어느 문서의 어디를 고쳤나) |
|---|---|---|---|
| 1 | 소개(i) 시트의 진입점이 없다 | 시트가 목록에만 있고 아무 화면에서도 열 수 없다 — 배선 누락 | 06-d 홈 요소 표에 `소개 단추 (i)` 행 추가 |
| 2 | 이어가기 시 어느 신비를 바치는지 정해져 있지 않다 | 어제 고통의 신비 3단에서 멈췄는데 오늘은 영광의 신비 요일이다 | **저장된 신비로 이어간다** — 끊긴 기도를 마치는 것이 이 기능의 목적이다. 자리에 신비를 함께 저장하고 카드에 신비 이름을 적는다. PRD FR-03 보강, 06-d 이어가기 카드 행·문구 보강 |
| 3 | "처음부터 다시"가 확인 없이 자리를 지운다 | 주 사용자(시니어)의 실수 탭 한 번에 진행이 사라진다. FR-30 의 "벌주지 않는다" 정신과도 어긋난다 | S3 확인 시트 추가. PRD FR-18 보강, 06-d 시트 표에 행 추가 |
| 4 | 지향을 지울 길이 없다 | 오타로 만든 지향이 영원히 남는다 | 지향 카드 **길게 누르기 → 삭제**. 진행이 있으면 "자리도 함께 지워집니다" 문구. PRD FR-05 보강, 06-d 지향 카드 행 보강 |
| 5 | 앱 이탈 뒤 복귀 화면이 없다 | PRD §8 은 "홈으로 안내"라 적었으나 iOS 는 떠난 화면으로 돌아온다. 돌아온 사용자가 멈춘 기도 화면에서 무엇을 눌러야 할지 모른다 | 기도 화면에 **B-5 멈춤 상태** 추가 — "이어서 바치기 / 홈으로". PRD §8 해당 행 수정, 06-d 기도 요소 표에 상태 추가, FR-15 의 알 상태에 "멈춤" 추가 |
| 6 | 완주 통계 "걸린 분"의 정의가 없다 | 멈춘 시간을 포함하면 어제 멈춘 기도가 "1,380분"이 된다 | **기도 화면에 머문 시간의 합**(멈춘 시간 제외). 06-d 완주 요소 표 보강 |
| 7 | (시제품) v4 가 진행 자리를 지향별로 저장하지 않는다 | FR-04 위반 — S-5 의 5번 걸음이 깨진다 | 명세는 맞다. **07 개정 목록**에 올린다 (PRD §10) |

**정직하게 적어 둘 것.** 결함 2·3·4·5 의 처방은 제품 결정이다. 각각 가장 보수적인 쪽 — 사용자의 진행을 잃지 않는 쪽 — 을 기본값으로 택했다. 공방장이 다르게 보면 이 표의 처방 칸만 고치면 되고, 나머지 문서는 이 표를 따른다.

## 5. 이 문서가 통과시키는 게이트

07 로 넘어가기 전에 이 문서가 답해야 하는 것 셋이다.

| 게이트 | 질문 | 지금 |
|---|---|---|
| 화면 목록이 닫혔나 | §1 표 밖의 화면·시트가 필요한 시나리오가 있나 | 없다 — S-1~S-11 전부 §1 안에서 걸어졌다 |
| 시나리오가 전부 걸어지나 | ✗ 가 남아 있나 | §4 처방을 세 문서에 반영한 뒤 **0건**. 결함 7 은 07 의 것 |
| 무소속 FR 이 없나 | 어느 화면에도 속하지 않는 요구사항 | 0건 (PRD §5-3 이 이미 검사했다. 이 문서의 §1 담는 요구사항 칸이 그것을 화면 지도 위에서 다시 보인다) |

**07-a(유저 플로·와이어프레임)는 이 문서가 대신한다.** §2 가 유저 플로이고, 화면이 3개라 와이어프레임은 06-d 의 요소 표로 충분하다. 어휘 문서 §7-1 의 "생략 가능 — 생략을 명시" 조항에 따라 여기 명시한다.
