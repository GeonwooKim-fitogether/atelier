## 2.5 시장 1위 완전 분해 — Hallow (Category King)

> 시장에서 *유일하게 진짜 사업 형태로 운영 중*인 경쟁자. 다른 경쟁자 (Memorare·Pocket Rosary·Wrist Rosary 등)는 신생·소규모. **Hallow의 장단점을 완전 분해하고 그 약점을 채우는 것이 우리 차별의 핵심.**

### Layer 1 — 재무·규모

| 항목 | 수치 |
|---|---|
| 창업 | 2018 (8년차) |
| 펀딩 | **$157M** (6 라운드·17 투자자 — Contrary·Uncork·General Catalyst) |
| 직원 | 333명 (2026.04) |
| 연 매출 | $3M~$51.4M (월 ~$1M) |
| 누적 다운로드 | **1,000만+** (월 신규 ~100만) |
| MAU | 1.3M |
| 누적 기도 횟수 | 6억+ (2024.08) |
| 비-가톨릭 비율 | **40%** (명상·일반 기도 사용자 흡수) |

### Layer 2 — 사용자 segment·가격 모델

| segment | 가격 |
|---|---|
| 기본 | 무료 (광고 없음) |
| 개인 월 | $9.99/월 |
| 개인 년 | $69.99/년 |
| **가족 (6 계정)** | **$119.99/년** |

| **본당 패키지** | **parish-wide subscription** (별도) |

→ **모든 segment 커버 완료**. 우리는 *다른 모델* 필요 (평생 결제 등).

### Layer 3 — 기술 stack

- iOS·Android 풀 지원
- **CarPlay 지원** (iOS 15.0+·무료 계정도)
- 셀럽 voice (Mark Wahlberg·Jonathan Roumie·Scott Hahn 등 사전 녹음)
- 통합 콘텐츠 (묵주·명상·성경·sleep·challenge)
- 본당 단체 관리 시스템
- 다국어 일부 (영어·스페인어 일부·이탈리아어)

### Layer 4 — Hallow 강점 (1위로 만든 것)

- **셀럽 voice 차별** — 영어권 인지도 폭발
- 통합 패키지 — 묵주만 X·신앙 전 영역
- CarPlay 선점 — 운전 사용 자리
- 풍부한 segment·가격 모델
- 비-가톨릭 40% 흡수 — 명상 시장도 동시
- 본당 B2B 채널 — 단체 도입 자리
- $157M 자본력 — 마케팅·인플루언서 압도

### Layer 5·6 — Hallow 약점 → 우리가 채울 자리 (CEO 인사이트 반영)

| Hallow 약점·빈 자리 | → | 우리가 채울 자리 |
|---|---|---|
| 영어만 (한국어·포르투갈어·스페인어 통합 X) | → | **한국어 + 4언어 통합** (KR·BR·MX·US WYD 2027) |

| $9.99/월 페이월 — 한국 무료 default 시장 거부 | → | **평생 결제 $19~$49** (Hallow 1/4·매년 갱신 X) + Founding $9~$19 |
| 한국 신비 묵상·청원/감사·신령성체 기도문 정합 X | → | **한국 전통 기도문 풀 정합** + 한국 사제 voice clone |

| 잠자기 전 모드 = sleep 콘텐츠 별도 (묵주기도 자동 종료 X) | → | **묵주기도 잠자기 전 모드** (점진적 음량·자동 종료·Calm/Headspace UX) |
| 아시아·LATAM 진출 안 함 (영어권 집중) | → | **한국·아시아·LATAM 시퀀스 진출** (WYD 2027 거점·Padre Fábio 1,500만 인플루언서) |

### 차별 한 줄 결론

> Hallow가 영어권·멀티 패키지·구독 모델로 1위. 우리는 **한국어/다국어 + 단일 목적 + hands-free 통합 + 평생 결제**로 *Hallow가 안 가는 자리*를 정면 회피하며 진입. WYD 2027 + 아시아 + LATAM 권역은 Hallow 비어있는 글로벌 시장.

## 5. Wedge 선정 (1차 시장·segment)

**Wedge = 한국 매일 묵주기도 헤비 신자 (Persona A)**

이유:
- **CEO 본인 1차 검증 가능** (직접 사용자)
- 한국 가톨릭 600만 중 미사 참례 90만의 30~50% = 27~45만 잠재
- 매일 사용 = 높은 retention 가능
- 한국 거점 + WYD 2027 = 글로벌 확장 자리

**확장 순서**:
1. **Year 1**: 한국 핵심 신자 (Persona A) — V1
2. **Year 1 후반**: 한국 시니어 (Persona B) + 라이트 (Persona C) — V1.5
3. **Year 2 (WYD 2027 전후)**: 한국 가족 (Persona D) + WYD 청년 (Persona E) — V2 다국어
4. **Year 3+**: 글로벌 4 권역 (KR·BR·MX·US) 정착

## 5.5 시장 진입 시퀀스 전략 (1차·2차·3차·4차)

> Wedge 1차에서 검증 → 인접 권역으로 단계적 확장 → 결국 **가장 큰 글로벌 가톨릭 시장** (스페인·포르투갈어권 = 브라질·멕시코·스페인·라틴 아메리카 = 압도적 다수) 도달. **Hallow가 영어권에 집중한 사이 비영어권 글로벌 자리를 선점.**

- **시점**: Y1 (2026~2027)
- **시장**: 600만 가톨릭 · 매주 미사 90만 · 매일 묵주기도 도전자 27~45만
- **Why**: CEO 본인 검증 가능 · 한국 가톨릭 무료 default 시장 정합 · 한국어 빈자리 · iOS 26.4 entitlement 새 출시 (CarPlay voice)

- **목표 (Y1)**: 3,000~22,500명 (1~5% 도달)
- **선행 조건**: V1 출시 · Persona A·B 검증
