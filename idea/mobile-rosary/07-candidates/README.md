# 07-d 후보 열 개 — 같은 엔진, 다른 재료

> 한 줄 요지: **`engine.js` 하나(77단계 · 상태 기계 · 지향별 자리 저장 · 음성 · 진동) 위에 껍데기 열 개(`d01`~`d10`)를 입혔다.** 엔진이 같아서 월드컵에서 이긴 부분을 후보 사이에 갈아 끼울 수 있다.

앞선 열 개(`g01`~`g10`)는 **구조만 다르고 시각은 기본값**이어서 공방장 판정으로 폐기됐다. 이번 열은 `frontend-design` 스킬의 절차를 따라 코드보다 먼저 **토큰 체계**(이름 붙인 색 대여섯 · 한글 서체 두 역할 · 레이아웃 한 문장 · 시그니처 하나)를 정하고, 그 시그니처를 **대상의 세계**에서 가져왔다. 방향 정의는 [`../07-d-design-directions.md`](../07-d-design-directions.md)에 있다.

## 파일

| 파일 | 무엇 |
|---|---|
| `engine.js` | 고정 부분. 06-prd §1 · 06-screen-spec 비화면 채널 · 06-screen-map 결함 2·5·7 처방(저장된 신비로 이어감 · 멈춤 상태 · 지향별 저장)이 들어 있다 |
| `d01-najeon.html` ~ `d10-grid.html` | 껍데기 열 개. `<script src="engine.js">` 로 엔진을 부른다 |
| `build.mjs` | 엔진을 인라인해 자체완결 파일을 `dist/` 에 만든다 |
| `strip.mjs` | `dist/` 를 아티팩트 게시용으로 벗겨 `art/` 에 둔다 (아티팩트가 doctype·head·body 를 스스로 씌우기 때문) |
| `shots/` | 후보마다 네 순간(`open` · `mine` · `resume` · `done`) 스크린샷. `?demo=<순간>` 으로 그 상태를 바로 연다 |
| `worldcup.mjs` | 스크린샷과 아티팩트 링크를 모아 월드컵 화면 `worldcup.html` 을 만든다 (생성물은 커밋하지 않는다 — 840KB) |
| `urls.json` | 게시된 아티팩트 주소. `worldcup.mjs` 와 `../prompts-page.mjs` 가 함께 읽는다 |

```bash
node build.mjs && node strip.mjs   # dist/ 와 art/ 갱신
node worldcup.mjs                  # worldcup.html 생성
```

## 후보 열 개

| # | 방향 | 시그니처 (기억에 남기려는 하나) |
|---|---|---|
| 1 | 자개 | 알이 원이 아니라 불규칙한 자개 조각이다 |
| 2 | 조각보 | 77단계가 곧 조각보의 조각 — 진행률이 아니라 만들어지는 물건 |
| 3 | 사경 | 세로쓰기, 앱은 먹빛 내 차례는 주사빛, 한 단마다 낙관 |
| 4 | 종 | 소리처럼 퍼지는 동심원, 다섯 신비가 다섯 겹 |
| 5 | 등불 | 진행이 곧 밝기, 내 차례에 심지가 살아난다 |
| 6 | 손 | 알 하나가 화면 너비의 3분의 1 |
| 7 | 전례색 | 신비마다 화면 전체 색이 바뀌고 알은 금빛 실선 |
| 8 | 침묵 | 숨쉬는 점 하나, 두드리면 거대한 숫자가 4초 |
| 9 | 판화 성모 | 그라데이션 없는 3색 목판, 묵주는 모은 두 손 아래 |
| 10 | 격자 | 거대한 모노 숫자가 화면 밖으로 넘쳐 잘린다 |

주소는 `urls.json` 에 있다.

## 후보를 하나 더 넣을 때

`dNN-이름.html` 을 만들고, 네 순간을 `?demo=` 로 렌더할 수 있게 하고, `worldcup.mjs` 의 `C` 배열에 한 줄을 더한다. 밖에서 받은 그림 후보(Claude Design · Stitch 등)는 `shots/` 에 네 장을 넣고 `url` 없이 같은 배열에 넣는다.

## 서체에 관한 정직한 한계

이 검증 환경은 외부 웹폰트를 받지 못한다(스크린샷을 찍을 때 `googleapis`·`gstatic` 요청을 막는다 — 막지 않으면 프록시에서 멈춘다). 그래서 `shots/` 의 그림에는 각 방향이 지정한 한글 디스플레이 서체가 아니라 **대체 서체**가 나온다. 색·배치·시그니처는 그대로지만 **조판의 인상은 실제 기기에서 열어야 확인된다.**
