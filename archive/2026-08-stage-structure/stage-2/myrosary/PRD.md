## 1. 방향성 한 문장

사용자 **[이동 중 기도자]** 가 **[대중교통 자투리 시간]** 에서 **[실물 휴대의 불편, 기존 도구의 페이스 강제와 진행 소실, 매번의 준비 비용]** 을 겪기에 **[내 페이스로 진행되고 위치가 기억되며 열면 바로 시작되는 포켓 묵주기도]** 가 필요하다.

## 2. As is / To be

## 3. 피처별 유저 스토리

### F1. 이어서 바치기 (진행 기억) — 1번 기능

- **AS** 이동 중 기도자
- **I WANT** 앱을 열면 마지막으로 바친 위치(몇 단, 몇 알)에서 한 탭으로 이어가기를
- **SO THAT** 환승·하차로 끊긴 기도가 소실되지 않고, "어디까지 했더라"를 되짚지 않는다

**Acceptance Criteria**
- Given 어제 영광의 신비 3단 4알에서 앱을 닫았다, When 오늘 앱을 열면, Then 첫 화면에 "이어서 바치기 — 영광의 신비 3단 · 4알부터"가 보이고 한 탭으로 그 위치의 기도 화면이 열린다.
- Given 진행 중 전화·잠금 등으로 앱이 중단됐다, When 다시 열면, Then 알 하나의 오차도 없이 같은 위치가 복원된다.
- Given 이어가지 않고 새로 시작하고 싶다, When "새 기도"를 선택하면, Then 기존 진행은 이력에 남고 새 세션이 시작된다.

### F2. 내 페이스 진행 (자동 진행 없음)

- **AS** 이동 중 기도자
- **I WANT** 화면 하단의 큰 탭존을 탭할 때만 다음 알로 넘어가고, 절대 저절로 진행되지 않기를
- **SO THAT** 영상·오디오처럼 남의 속도에 끌려가지 않고 내 호흡대로 바친다

**Acceptance Criteria**
- Given 기도 화면이다, When 탭존을 탭하면, Then 다음 알로 진행되고 짧은 햅틱이 온다(화면을 보지 않아도 진행 확인).
- Given 아무 조작도 하지 않는다, When 시간이 흘러도, Then 진행·재생·화면 전환이 일어나지 않는다.
- Given 실수로 넘겼다, When 뒤로 스와이프(또는 이전 버튼), Then 한 알 뒤로 돌아간다.

### F3. 오늘의 신비 자동 (무준비)

- **AS** 이동 중 기도자
- **I WANT** 앱을 열면 오늘 요일의 신비(환희·고통·영광·빛)가 자동 선택되고 각 단의 한 줄 묵상이 함께 보이기를
- **SO THAT** 검색·확인 없이 즉시 시작한다

**Acceptance Criteria**
- Given 오늘이 수요일이다, When 새 기도를 시작하면, Then 영광의 신비가 기본 선택돼 있다(변경 가능).
- Given 각 단을 시작한다, When 단 화면에 들어서면, Then 그 신비의 이름과 한 줄 묵상이 기도문 위에 보인다.

### F4. 한 손 · 저마찰 (이동 중 UX)

- **AS** 서서 이동 중인 기도자
- **I WANT** 한 손 엄지만으로 전 과정을 조작하고, 기도 중 화면이 꺼지지 않기를
- **SO THAT** 손잡이를 잡은 채로도 기도가 끊기지 않는다

**Acceptance Criteria**
- Given 기도 화면이다, When 모든 조작을 확인하면, Then 진행·역행·일시정지가 화면 하단 1/3 안에서 끝난다(상단 터치 불필요).
- Given 기도 중이다, When 30초간 무조작이어도, Then 화면이 꺼지지 않는다(옵션으로 끔 가능).
- 광고·팝업·알림 인터럽트가 기도 화면에 절대 나타나지 않는다.

### F5. 기간 기도 트래킹 (기간형 습관)

- **AS** 9일기도·성월을 작정한 기도자
- **I WANT** 기간을 설정하면 일별 완주가 달력에 기록되기를
- **SO THAT** 며칠째인지 수기로 세지 않고, 작정한 기간을 끝까지 간다

**Acceptance Criteria**
- Given 9일기도를 시작일과 지향과 함께 설정했다, When 하루의 5단을 완주하면, Then 그 날짜가 완주로 표시되고 "N일째 / 9일"이 홈에 보인다.
- Given 하루를 걸렀다, When 다음 날 열면, Then 질책 없이 이어갈 길("계속하기")이 기본으로 제시된다 (죄책감 UX 금지 — 반증 "기도는 아날로그" 정서 존중).

### F6. 기도문 상시 표시 (초심자 겸용)

- **AS** 순서가 헷갈리는 기도자
- **I WANT** 현재 알에서 바칠 기도문 전문이 항상 화면에 있기를
- **SO THAT** "아는 사람 전용" 앱이 되지 않는다 (외부 흔적의 기존 앱 불평 직접 대응)

**비목표 (이번 사이클에서 만들지 않는 것):** 오디오 묵상 콘텐츠(Hallow 영역) · 커뮤니티/공유 · 계정·서버 동기화(로컬 우선) · 결제 · 다국어(한국어 우선).

## 4. Moat & Wall

direction.md §6이 정본. 요지 — Moat: 개인 기도 이력의 누적 + 한국어 이동 중 기도 UX 선점 / Wall: 무료 대체재·유료 반감·발견성·공식 생태계 재편. **잠정 판정: "개인·틈새 제품" 판돈에서 Moat ≥ Wall (추인 대기).**

## 5. Kill Signal (정량 1개 — 제안, CEO 확정 대기)

**"MVP로 바친 최초 2회의 기간 기도(예: 9일기도 2회)에서, 앱 경유 일별 완주율이 두 번 모두 60% 미만이면 Kill."** — 기간형 지표인 이유는 Stage 1 제약 ①(Depth가 기간형이므로 상시 사용률로 재면 부당하게 죽는다).
